Response Headers 比對步驟
  1. 在此頁按 F12 → Network，重新整理。
  2. 分別點兩個 iframe 的 exec 請求 → Headers → Response Headers。
  3. 查 x-frame-options：若為 SAMEORIGIN，GitHub 無法嵌入。
  4. 另開頂層分頁直接訪問 /exec，比對標頭是否不同。
  5. 到 GAS 開 /exec?diag=1 執行「檢查 GAS 專案 HTML 檔案」。
  6. 到 Apps Script → 執行作業，查看 [doGet] mode=... 是否有失敗。
